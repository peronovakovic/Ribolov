# Ribolov

Informacioni sistem za upravljanje sportskim ribolovom Republike Srpske.

Projekt je u fazi specifikacije i pripreme razvoja. Prva operativna verzija obuhvata organizacije i prava pristupa, članstvo, dozvole, evidentiranje uplata, ribolovna područja, terenske kontrole s offline radom i osnovne izvještaje.

## Dokumentacija

- [Izvorni funkcionalni koncept](docs/RibolovniSistemRS.docx)
- [Detaljna specifikacija prve operativne verzije](docs/Specifikacija_prve_operativne_verzije.md)

Specifikacija je verzija 0.1, prijedlog za usaglašavanje. Sadrži 118 zahtjeva, 44 scenarija prihvatanja i 15 predloženih poslovnih odluka.

## Razvoj

Implementacija aplikacije još nije započeta. Upute za pokretanje, izgradnju i testiranje bit će dodane uz početnu implementaciju.
